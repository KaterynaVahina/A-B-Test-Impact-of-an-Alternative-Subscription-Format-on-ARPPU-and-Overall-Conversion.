# A-B-Test-Impact-of-an-Alternative-Subscription-Format-on-ARPPU-and-Overall-Conversion.
Наш продукт - вебсайт з записаними онлайн-курсами, що доступні за підпискою. Раніше на сайті була доступна тільки одна опція: доступ до усіх курсів за $29.99 на місяць. Ми вирішили протестувати альтернативний формат та додати можливість отримати доступ до курсів лише в одному напрямку за $9.99 на місяць.

## Мета — відпрацювати такі навички:

- Формулювання гіпотези та визначення цільової метрики (ARPPU) і допоміжних метрик (конверсія, ARPU, кількість підписок).
- Розрахунок необхідного розміру вибірки та тривалості тесту за допомогою Evan’s Awesome A/B Tools.
- Аналіз результатів: порівняння конверсії, ARPU, ARPPU, загального доходу між контрольною та тестовою групами.
- Оцінка статистичної значущості (p-value < 0.0001) та формулювання рекомендацій щодо впровадження змін.

## Результати тесту

- **Контрольна група (тільки $29.99)**: 13623 користувачів, 411 покупок → конверсія 3.02%, ARPU = $1.95.
- **Тестова група ($29.99 + $9.99)**: 14012 користувачів, 652 покупки → конверсія 4.65% (+54%, p-value < 0.0001), ARPU = $2.33.
- Загальний дохід зріс з $26 501 до $32 652.

## Висновки

- Новий формат з двома підписками значно підвищив конверсію та ARPU.
- Не втратив дорогу аудиторію — кількість покупців за $29.99 майже не змінилася.
- Привернув 232 нових платників за $9.99.
- Економічно вигідний — загальний дохід збільшився на 23%.

## Рекомендації

- Впровадити новий формат ($29.99 + $9.99) для всіх користувачів.
- Залишити дорожчу підписку — вона залишається основним джерелом доходу.
- Продовжувати пропонувати дешевшу підписку — вона привертає нових платників.
